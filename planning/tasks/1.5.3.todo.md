## Notes (facts from Analysis, risks, helper signatures)

- Helpers already in test file (lines 449-491), reuse only:
  - `bf_haversine_km(x, y, gx, gy)` -> km vector from data points to one grid point, R = 6371.0088.
  - `bf_fixed(x, y, gx, gy, bw)` -> unnormalized sum over `d < 3*bw`, one value per grid point.
  - `bf_adaptive(x, y, gx, gy, pilot, min_bw)` -> pilot via `bf_fixed`, `dmax <- max(p)` over the supplied grid, `ratio = p/dmax`, `scale = min + (pilot-min)/(1+sqrt(ratio))`, then per-cell sum with cutoff `3*scale`.
  - `bf_expect(res, ref, info)` -> per-element relative diff <= 1e-10; zero reference requires zero result.
  - `bf_destination`, `bf_tangent_bearing` exist but are not needed here.
- `bf_adaptive`'s `dmax` is taken over the grid passed in, so the reference itself encodes template dependence. Test 1 is consistent with that by construction.
- `kde_adaptive(x, r, pilot_bandwidth, min_bandwidth = NULL)` in `R/geodensity.R:231`. Default: `min_bandwidth <- pilot_bandwidth * 0.1` (line 251). Validation: `min > 0`, `min < pilot`. Returns a SpatRaster built from `terra::rast(r)`.
- Input convention in the file: `terra::vect(df, geom = c("lon","lat"), crs = "OGC:CRS84")` and `terra::rast(extent=..., resolution=..., crs="OGC:CRS84")`. Reuse this.
- Risk: `expect_identical` on two SpatRaster objects compares S4/external-pointer state and is likely to fail even when the values match. Compare `terra::values()` instead. This is a small deviation from the literal spec wording; it keeps the spirit (exact equality of output).
- Risk: existing Test 30 (lines ~404-416) already compares default vs explicit min with `min_bandwidth = 5` at pilot 50, but not with `expect_identical`. The new test 4 is not a duplicate.
- Risk: the zero-density template must be far enough that the Rust search returns 0 for every cell. Points near -100, template -20..-10: cutoff is 3*50 = 150 km, distance is thousands of km, so 0 is expected. Confirm with `bf_fixed` before asserting.
- Risk: for test 3, the shared cell must have nonzero pilot on both templates. Choose the cell near the point cloud.
- Risk: `ratio == 1` at the global max cell makes sqrt and no-sqrt formulas agree there. The demonstration must use cells with ratio strictly between 0 and 1 (the bulk of the grid, which the seeded set provides).
