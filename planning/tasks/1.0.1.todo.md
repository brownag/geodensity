## Notes

Facts from Analysis:
- Current `test:` target (Makefile lines 44-46) runs `devtools::load_all(quiet=TRUE); source('inst/tinytest/test_geodensity.R')`. It never reads results, so a failing `expect_*` does not change the exit code. That is why the gate needs to change.
- `inst/tinytest/test_geodensity.R` header: loads `tinytest`, `terra`, `geodensity`, then runs `expect_true`/`expect_equal` blocks.
- `<scratchpad>/gate/test_fail.R` exists (66 bytes): `expect_equal(1, 2, info = "deliberate failure")` plus `expect_true(TRUE)`. Expect 2 expectations, 1 failed.
- `planning/STATE_1.md` already has uncommitted modifications; step 8 appends to it and must not reset it.
- `src/rust/vendor` must exist in the working tree for step 7. Confirm before the copy. If `git archive` already includes it, the copy is a no-op overwrite and is still fine.

Make escaping plan:
- The recipe uses no `$` inside the R code. `[[`/`[['result']]` replaces `$` so sh double quotes cannot expand anything. This avoids the `$$` problem entirely.
- `$(TEST_FILE)` is a Make variable, expanded by Make, and is intended.
- `\n` inside the sh double-quoted string passes through as a backslash-n, and R's single-quoted string turns it into a newline.
- `'` quoting for the path inside R: if the scratchpad path ever contains a `'`, it breaks. The current path has none.

Risks:
- If `as.data.frame()` does not work on the tinytest result (step 1), fallback: `x <- unlist(lapply(r, function(e) isTRUE(e[['result']])))` with `n <- length(x)`, `f <- sum(!x)`. Use only if step 1 fails.
- `verbose` is left at the default, so failure details print. Output is noisier but shows why a test failed.
- Errors inside a test file: tinytest records them as failed expectations, so they count toward `f`.
- Revalidation (step 7) needs `devtools::load_all` to compile the Rust backend from the vendored source in each temp directory. This may be slow and may need the vendor config to work offline.
- Step 7 runs `Rscript` with the gate line taken from this commit's Makefile. Older commits do not have `TEST_FILE`, so the recipe is run directly, not via `make`.
